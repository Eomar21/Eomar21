### Transcriber

Transcriber (https://github.com/Eomar21/transcriber) is a desktop app that turns recordings into timestamped transcripts, with optional speaker labels, and gives feedback on how you speak. Everything runs on your own computer, so audio is never uploaded.

It is a .NET MAUI app for Windows and macOS. The services layer (local Whisper, voice activity detection, speaker detection, export) has no UI dependencies, and the app uses MVVM view models. Tests include end-to-end transcription of real recordings in English, Dutch, Arabic and Spanish, checked by word error rate, plus UI automation tests. CI builds and publishes releases.

Documentation: https://eomar21.github.io/transcriber/
